# Security

Please report anything security-related privately, not in a public issue: email **agenticfinancegraph@proton.me** with a description, the steps to reproduce and the time (UTC). We reply as soon as we can and credit the reporter if they wish.

Scope: this repository, the MCP endpoint at `https://agenticfinancegraph.com/mcp`, the public API and the paid evidence packs at `https://agenticfinancegraph.com/check/`.

Everything in this repository is read-only by design. It holds no keys and cannot sign or move funds.
